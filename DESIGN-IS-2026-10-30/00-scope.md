# 00. 감사 범위

## 무엇을 감사하나
- **골프 바이블 React 프로토타입** (`prototype/`): 실제 Expo 앱을 만들기 전에 화면 흐름을 확인하려고 만든 웹 시제품. 폰 프레임 안에서 홈 / 교본 / 레슨 / 통과 테스트 / 기록 / 멘탈 / 30초 회고 / 첫 실행 화면이 동작한다.
- 참고 자료: 설계 문서 `docs/superpowers/specs/2026-10-30-golf-bible-app-design.md`, 정적 시안 `docs/superpowers/specs/mockups/golf-bible-v2.html`.
- 감사 대상은 폰 프레임 안의 앱 화면. 바깥의 "프로토타입 도구" 패널(날짜 넘기기, 테마 전환)은 검토용이라 제외한다.

## 주 사용자와 주 작업
- 사용자: 입문자부터 100타 언저리의 아마추어 골퍼. 연습장 타석에서 한 손으로 폰을 본다.
- 주 작업: 앱을 열자마자 오늘 할 레슨과 드릴을 알고, 드릴을 하나씩 체크하며 연습을 끝낸다.
- 보조 작업: 레슨 영상 보기(구간 이동), 통과 테스트 결과 입력, 성장 기록 확인, 멘탈 카드 확인, 회고 남기기.

## 제약
- 최종 형태는 React Native (Expo). 이 프로토타입은 React 18 + Tailwind 웹 번들.
- 한국어 전용, 라이트/다크 모두 지원, 한 손 조작(터치 영역 44pt 이상).
- 영상은 촬영 전이라 잔디 화면으로 재생을 흉내 낸다 (실제로는 유튜브 일부 공개 영상).

## 비교 대상
- 체계 없는 골프 유튜브 영상 모음 (사용자가 해결하려는 문제).
- 정적 시안 2 (사용자가 고급스럽다고 승인한 방향).
