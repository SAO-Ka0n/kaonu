# 골프 바이블 앱 설계

작성일: 2026-10-30
상태: 초안 (사용자 확인 전)
참고 시안: `docs/superpowers/specs/mockups/golf-bible-v2.html` ("골프 바이블 시안 2". 브라우저로 열면 홈 / 교본 레슨 / 기록 / 멘탈 화면을 눌러 볼 수 있음. 색 토큰, 폰트, 잔디 줄무늬 임시 영상 화면은 이 파일의 `<style>` 맨 위 `:root` 블록이 기준)

## 1. 왜 만드는가

골프 유튜브 영상은 많지만 사람마다 말이 다르고 순서가 없다. 수학의 정석처럼 "이걸 끝내면 다음으로" 가는 교안이 없다. 그래서 아마추어는 연습장에 가도 목적 없이 공만 치다 온다.

골프 바이블은 **순서가 있는 골프 교본 + 매일 따라 하는 연습 루틴**이다. 연습장에 도착해서 앱을 열면 "오늘 할 레슨과 드릴"이 바로 보이고, 단원을 통과할 때마다 다음 단원이 열린다. 자세와 스윙뿐 아니라 멘탈 관리도 교본과 매일 루틴에 함께 들어간다. 이렇게 쌓인 연습 기록이 사용자 본인의 루틴 시스템이 된다.

## 2. 목표 / 비목표 / 반목표

### 목표 (v1)
- 실제 폰에서 돌아가는 앱 (Expo, React Native). 개발 중에는 브라우저에서도 확인 가능.
- 교본: 4파트 12단원. 단원마다 영상 레슨 여러 개와 통과 테스트.
- 홈: 오늘의 레슨, 오늘의 드릴 체크리스트, 교본에서 내 위치, 오늘의 멘탈 카드.
- 레슨 화면: 영상(구간 바로가기 포함), 자세 체크포인트, 연습 드릴, 단원 통과 기준.
- 기록: 연속 연습일, 통과한 단원 수, 누적 공 개수, 통과 테스트 결과 추이, 연습 일지와 회고.
- 단원 잠금: 통과 테스트를 통과해야 다음 단원이 열림.
- 교본 내용(단원, 레슨, 드릴, 체크포인트, 영상 구간)은 코드와 분리된 데이터 파일로 관리해서, 사용자가 직접 내용을 고칠 수 있음.

### 비목표 (v1에서 안 함)
- 로그인, 서버, 여러 기기 동기화. 기록은 폰 안에만 저장.
- 결제, 구독, 앱 스토어 출시.
- 커뮤니티, 코치 피드백, AI 스윙 분석.
- 푸시 알림 (v1 이후 첫 후보).
- 실제 촬영 영상 (아직 없음. 임시 화면으로 대신하고, 영상이 생기면 데이터 파일에서 주소만 바꿈).

### 반목표 (이렇게 되면 실패)
- 또 하나의 "순서 없는 영상 모음"이 되는 것. 모든 화면은 "지금 어느 단원, 다음에 뭘 할지"를 보여 줘야 한다.
- 홈이 복잡해서 연습장에서 폰을 열었을 때 오늘 할 것을 바로 못 찾는 것.
- 게임처럼 점수만 쌓이고 실제 실력과 관계없는 진행 표시. 진행은 통과 테스트 결과에 근거해야 한다.

## 3. 사용자와 사용 장면

- 대상: 입문자부터 100타 언저리의 아마추어.
- 주 사용 장면: 연습장 타석에서 폰을 한 손으로 보며 연습. 영상을 보고, 드릴을 하나씩 체크하고, 끝나면 30초 회고를 적는다.
- 그래서 화면은 한 손 조작, 큰 터치 영역, 짧은 문장이 기본이다.

## 4. 사용자가 정한 것

- 형태: React Native (Expo) 앱.
- 레슨 영상은 직접 촬영한다.
- 홈은 "오늘 레슨"이 가장 먼저 보이고, 교본에서 내 위치가 함께 보인다 (시안 2 방향).
- 화면 구성: 홈 / 교본 / 기록 / 멘탈 4개 탭.
- 디자인 방향: 시안 2의 고급스러운 톤 (짙은 숲색, 밝은 회백색, 호박색 포인트 한 가지, 다크 모드 지원).
- 단원 구성 방향: 그립, 어드레스 같은 기초부터 시작해서 순서대로 진행.

## 5. 설계자가 정한 것 (확인 필요)

아래는 대화에서 정해지지 않아 설계자가 정한 것이다. 바꾸고 싶으면 알려 주면 된다.

### 5.1 교본 구조
| 파트 | 단원 |
|---|---|
| 기초 | 1 그립, 2 어드레스, 3 정렬 |
| 스윙 | 4 하프스윙, 5 풀스윙, 6 임팩트와 체중 이동 |
| 클럽별 | 7 드라이버, 8 어프로치, 9 퍼팅 |
| 코스와 멘탈 | 10 프리샷 루틴, 11 멘탈 관리, 12 코스 매니지먼트 |

- 단원 하나 = 레슨 4~6개 + 통과 테스트 1개.
- 레슨 하나 = 영상 1개(3~5분) + 영상 구간 3~5개 + 자세 체크포인트 3~4개 + 연습 드릴 3~5개.
- v1에는 12단원 전체의 뼈대(제목, 레슨 제목, 통과 기준)를 넣고, 1~5단원은 드릴과 체크포인트까지 예시 내용을 채운다. 나머지는 사용자가 채운다. 예시 내용은 일반적인 골프 레슨 상식 수준이며 사용자가 검수한다.

### 5.2 오늘의 레슨 고르는 규칙
1. 현재 단원 = 잠금 해제된 단원 중 아직 통과 못 한 가장 앞 단원.
2. 오늘의 레슨 = 현재 단원에서 아직 완료하지 않은 가장 앞 레슨.
3. 현재 단원의 레슨을 모두 완료했으면 오늘의 레슨 = 통과 테스트.
4. 오늘의 루틴 = 오늘의 레슨 드릴 + 멘탈 드릴 1개 (매일 순환).
5. 레슨 완료 = 그 레슨의 드릴을 모두 체크한 날이 하루 이상 있음. 영상 시청은 완료 조건이 아니다 (연습장에서 영상을 다시 안 볼 수도 있으므로).
6. 오늘의 레슨은 그날 처음 앱을 연 순간 정해지고, 자정까지 바뀌지 않는다. 드릴을 다 체크하면 홈은 "오늘 루틴 완료 + 회고" 상태가 된다. 그 아래 "다음 레슨 미리 하기" 버튼이 있고, 누르면 다음 레슨이 그날의 추가 레슨이 된다.
7. 통과 테스트 날의 루틴 = 통과 테스트 + 현재 단원 핵심 드릴 복습 1개(단원 데이터에 지정) + 멘탈 드릴 1개. 테스트 결과를 입력하면 그날은 연습한 날로 친다.

### 5.3 통과 테스트
- 단원마다 기준이 하나 있다. 예: "7번 아이언 10개 중 7개가 목표 방향 ±10m 안".
- 사용자가 결과를 직접 입력한다 (10개 중 몇 개). 기준 이상이면 통과, 다음 단원이 열린다.
- 실패해도 결과는 기록에 남고, 다시 도전할 수 있다. 횟수 제한은 없다.
- 기준이 "10개 중 N개" 형태로 표현하기 어려운 단원(예: 멘탈 관리)은 "체크리스트 전부 수행" 형태의 기준을 쓴다. 데이터 모델은 두 형태를 모두 지원한다.

### 5.4 레벨
- 레벨 = 통과한 단원 수 + 1 (Lv.1 ~ Lv.13). 레벨 이름은 현재 파트 이름 (예: "Lv.5 스윙").
- 시안에 있던 XP는 없앤다. 반목표(실력과 관계없는 점수)에 걸리기 때문이다. 대신 홈의 원형 진행 표시는 "현재 단원에서 완료한 레슨 비율"을 보여 준다.

### 5.5 기록
- 연습 세션 = 하루 단위. 그날 체크한 드릴, 공 개수(드릴에 적힌 개수의 합), 통과 테스트 결과, 회고(잘된 것 1개, 고칠 것 1개)를 저장.
- 연속 연습일 = 드릴을 하나라도 체크했거나 통과 테스트 결과를 입력한 날이 끊기지 않고 이어진 날 수. 날짜 기준은 폰의 현지 시간 자정.
- 그래프 = 최근 통과 테스트 결과 8회 (10개 중 몇 개), 통과선 표시.

### 5.6 멘탈
- 11단원(멘탈 관리)은 다른 단원과 같은 구조로 배운다.
- 멘탈 카드는 단원과 별도인 카드 묶음(`content/mental.ts`, 처음 15장 정도)이다. 카드 하나 = 원칙 한 줄 + 설명 한두 줄 + 오늘 할 멘탈 드릴 한 줄. "멘탈 카드"와 "멘탈 드릴"은 같은 카드의 두 부분이다.
- 처음부터 모든 카드를 쓸 수 있다. 하루에 한 장씩 순서대로 돌아가며 "오늘의 멘탈 카드"가 되고, 그 카드의 드릴이 오늘 루틴에 들어간다.
- 멘탈 탭 = 오늘의 멘탈 카드 + 지금까지 만난 카드 모음(오늘의 카드로 한 번이라도 나온 카드) + 지난 회고 목록.
- 루틴을 끝내면 30초 회고 입력 화면이 뜬다 (건너뛰기 가능).

### 5.7 영상 (사용자 결정: 유튜브 일부 공개)
- 사용자가 직접 찍은 영상을 유튜브에 "일부 공개"로 올린다. 앱은 유튜브 플레이어(WebView 기반, 예: `react-native-youtube-iframe`)로 재생한다. `expo-video`는 유튜브 주소를 재생하지 못하므로 쓰지 않는다.
- 데이터 파일의 레슨마다 `youtubeId`(영상 ID), `durationSec`(영상 길이, 직접 입력), `marks`(구간: 시작 초, 제목)를 둔다.
- 썸네일은 유튜브 썸네일 주소(`https://img.youtube.com/vi/<ID>/hqdefault.jpg`)에서 가져온다.
- `youtubeId`가 비어 있으면 시안의 잔디 줄무늬 임시 화면과 "영상 준비 중"을 보여 준다.
- 영상 구간을 누르면 플레이어의 seek 기능으로 해당 초로 이동한다.
- 영상은 인터넷이 있어야 재생된다. 오프라인 저장은 하지 않는다 (유튜브 약관상 불가).

### 5.9 설치와 내용 업데이트 (사용자 결정: 아이폰, 갤럭시 둘 다)
- 개발 중: 두 폰 모두 Expo Go 앱으로 실행한다.
- 갤럭시: EAS Build로 설치 파일(APK)을 만들어 직접 설치한다. 컴퓨터 없이 연습장에서 혼자 실행된다.
- 아이폰: 혼자 실행되는 버전은 애플 개발자 계정(연 회비)이 있어야 만들 수 있다. 계정이 생기기 전까지는 Expo Go로 쓴다. 빌드 설정(`eas.json`)은 미리 두 플랫폼 모두 준비한다.
- 교본 내용을 고친 뒤 폰에 반영하는 방법은 EAS Update로 한다 (다시 설치하지 않아도 앱을 열면 새 내용을 받음). 이 절차를 `content/README.md`에 쉬운 말로 적는다.

### 5.8 기술
- Expo (작성 시점 최신 안정 SDK), Expo Router (탭 + 스택), TypeScript.
- 저장: 기기 로컬 저장소 (AsyncStorage 수준이면 충분. 데이터 양이 작음).
- 교본 내용: `content/` 폴더의 TypeScript 데이터 파일. 타입으로 형식을 검사한다.
- 진행 계산(오늘의 레슨, 잠금, 레벨, 연속 연습일)은 화면과 분리된 순수 함수로 만들고 단위 테스트를 붙인다.
- 폰트: 시안 2와 같은 계열 (본문 Noto Sans KR, 숫자 Outfit), `expo-font`로 앱에 포함.
- 색: 시안 2의 색 토큰을 그대로 옮기고, 폰의 라이트/다크 설정을 따른다.

## 6. 화면

### 홈
- 날짜, 인사, 오늘의 주제 한 줄. 오른쪽에 레벨 원형 표시.
- 오늘의 레슨 카드 (짙은 숲색): 단원과 레슨 번호, 제목, 영상 썸네일, 예상 시간, 공 개수, 드릴 진행(n/5), "영상 보고 시작" 버튼.
- 오늘의 드릴 체크리스트 (누르면 체크).
- 교본에서 내 위치: 12칸 막대 (완료 / 현재 / 잠김).
- 오늘의 멘탈 카드.
- 루틴을 모두 체크하면 완료 메시지와 회고 입력으로 이어짐.

### 교본
- 4파트 12단원 목록. 상태: 완료 / 진행 중 / 잠김. 잠긴 단원은 눌러도 내용 대신 "앞 단원을 통과하면 열려요"를 보여 줌.
- 진행 중 단원은 레슨 목록이 펼쳐짐 (썸네일, 영상 길이, 상태).
- 레슨 화면: 영상, 영상 구간, 레슨 목표 한 줄, 자세 체크포인트, 연습 드릴(홈과 같은 체크 상태 공유), 단원 통과 기준.
- 통과 테스트 화면: 기준 설명, 결과 입력(0~10), 통과/재도전 결과.

### 기록
- 연속 연습일 (큰 숫자), 통과한 단원 수, 누적 공 개수.
- 통과 테스트 결과 그래프 (최근 8회, 통과선).
- 연습 일지 (날짜, 레슨, 결과), 지난 회고.

### 멘탈
- 오늘의 멘탈 카드, 멘탈 카드 모음, 회고 목록.

### 빈 상태
- 첫 실행: 짧은 시작 화면 1장 ("1단원 그립부터 시작해요") 후 홈. 기록 탭은 "첫 연습을 끝내면 여기에 쌓여요".

## 7. 제약
- 한국어 전용.
- 한 손 조작: 주요 버튼은 화면 아래쪽 절반, 터치 영역 44pt 이상.
- 오프라인에서도 영상 재생과 썸네일 외 모든 기능이 동작.
- 사용자는 개발자가 아니다. 교본 내용 수정 방법을 `content/README.md`에 쉬운 말로 적는다.

## 8. 빌더에게 맡기는 것
- 폴더 구조, 상태 관리 방식, 컴포넌트 분리.
