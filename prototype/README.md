# 골프 바이블 프로토타입 (버리는 시제품)

실제 Expo 앱을 만들기 전에 화면 흐름을 확인하려고 만든 React 웹 시제품이에요.
최종 앱 코드가 아니에요. 교본 데이터 형식(`src/data/types.ts`)과 진행 규칙(`src/logic/progress.ts`)만 실제 앱으로 옮겨 갈 후보예요.

- 실행: `pnpm install && pnpm dev`
- 한 파일 버전: `bundle.html` (브라우저로 바로 열림)
- 교본 내용: `src/data/content.ts` (12단원), `src/data/mental.ts` (멘탈 카드 15장)
